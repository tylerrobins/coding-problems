# STRUCTURE
For codewars, there is a directory for each language used.
Each problem is named with the following structure:
[kyu-level]-[problem-name]

# TYPESCRIPT
I run this for each script/problem
```zsh
pnpm dlx ts-node [kyu-level]-[problem-name].ts
```
Please make sure you have run pnpm install at the Typescript folder to ensure you have ts-node installed.
